1.1: Print statements, text, and numbers#

There are many libraries built for use in Python. Each library comes with a suite of functions and tools that you can reference and use, as long as you’ve loaded that library. Before we get to that though, let’s start with some ‘pre-built’ functions that we can use without havign to load any libraries.

The first program that many people learn to write is a “Hello, world!” program, which outputs the phrase _Hello, world!_To do so, we need the print() function. print() outputs whatever the object of the function is.

In this case, the object is text data, stored as a string. In Python, strings are indicated using either single (') or double (") quotations marks.

Let’s see it in action:

print('the world is waiting to be greeted')

the world is waiting to be greeted

Your turn!

In the code cell below, use the print command to output the string: Hello, world!

Tip

What was # for?

In Python, # denotes a comment. Comments can be used to annotate code to make it easier to read and understand. Python ignores everything on lines that begin with #. If the line just read write your code here, an error would be raised–you can try it and see!

#write your code here!

Solution (click to expand)

The code should read:

print("Hello, world!")

Text data is useful for inputting labels, descriptors, printing statements, etc. However, numerical data is also very useful.1 Numbers are stored as integers (whole numbers) or floats (decimals2).

Pause & Consider:

  1. Is this aligned with your prediction? If so, how did you know? If not, does it make sense in retrospect?

  2. Which value is an integer? Which is a float?

Solution (click to expand)

Python output an integer (15) when two integers were added (5+10); it output a float (15.0) when two floats were added (5.0+10.0).

Tip

A few notes about that code…

  • Readability: Space between values makes it easier to read (5 + 10 vs 5+10). Python ignores spaces unless they are in a string.

  • Function: There are two items in each print command: one string (acting as a label), and one calculation. Each item is separated by a comma–Python will print one and then the other, on the same line.
